# Logotipo de Busca Tumbas

logo-original.jpg es la imagen proporcionada por el usuario. logo-transparent.png es la adaptación con fondo transparente utilizada como base de los recursos.

Para regenerar las variantes web, Android y pantallas de inicio, ejecutar scripts/generate-brand-assets.ps1 en Windows. Se conservan los originales; las variantes están en assets/brand y android/app/src/main/res. El icono nativo se actualiza al generar e instalar una nueva versión Android.
